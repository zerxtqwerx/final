В круге из k карточек для каждой тройки подряд идущих должны быть хотя бы две одинаковые. 
Это значит, что в расстановке не может быть двух подряд идущих различных чисел,
иначе тройка, начинающаяся с первого из них, будет содержать три разных числа. 
Также не может быть паттерна X Y X. 
А значит любая допустимая расстановка состоит из одного "доминантного" числа A, 
которое встречается много раз, разделяя другие числа. Другие числа могут вставляться между парами A.

Алгоритм:

1. Подсчитываем частоты каждого числа

2. Если нет ни одной пары (частоты ≥2), ответ 0.

3. Для каждого числа A с частотой fa ≥ 2:

    Количество "слотов" между парами A: slots = fa/2

Остальные числа делим на:

    "Безопасные" (частота ≥2): pOthers = сумма(f/2), sOthersSafe = сумма(f%2)

    "Чистые одиночки" (частота =1): sPureSingles

    Безопасный блок: safeBlockSize = 2*pOthers + sOthersSafe

Если safeBlockSize > 0, он занимает 1 слот

Нужно слотов: blocksNeeded = (safeBlockSize>0?1:0) + sPureSingles

Если blocksNeeded ≤ slots: candidate = fa + safeBlockSize + sPureSingles

Иначе если нет безопасного блока: candidate = fa + min(sPureSingles, slots)

Иначе: candidate = fa + safeBlockSize + min(sPureSingles, slots-1)

Ответ = max(candidate) или 0 если <3

Сложность: O(n) на тест
