# Оптимальная покупка ключей доступа

## Условие

У вас есть группа из `n` студентов, для которых необходимо приобрести доступ к онлайн-курсу. В магазине доступны два вида ключей:

- **Индивидуальный ключ**: стоит `a` рублей и даёт доступ одному студенту.
- **Групповой ключ**: стоит `b` рублей и даёт доступ группе до трёх студентов включительно.

Групповой ключ можно использовать и для меньшего количества студентов (одного или двух), при этом его стоимость не изменяется.

Необходимо определить **минимальную сумму**, которую нужно потратить, чтобы обеспечить доступ для всех `n` студентов.

### Входные данные

- Первая строка: целое число `t` (`1 ≤ t ≤ 10⁴`) — количество наборов входных данных.
- Следующие `t` строк: три целых числа `n, a, b` (`1 ≤ n, a, b ≤ 10⁸`).

### Выходные данные

Для каждого набора — одно целое число: минимальная сумма в рублях.

## Алгоритм

Задача решается жадным подходом с рассмотрением двух вариантов для каждой группы:

1. **Для полных троек** (групп по 3 студента):
   - Либо один групповой ключ за `b` рублей.
   - Либо три индивидуальных ключа за `3·a` рублей.
   - Выбираем минимум: `min(b, 3·a)`.

2. **Для остатка** (0, 1 или 2 студента):
   - **0 студентов** — дополнительных затрат нет.
   - **1 студент** — либо индивидуальный ключ (`a`), либо групповой (`b`). Выбираем `min(a, b)`.
   - **2 студента** — либо два индивидуальных (`2·a`), либо групповой (`b`). Выбираем `min(2·a, b)`.

### Формула
full = n // 3
rem = n % 3
cost = full × min(b, 3·a) + extra(rem)

где:
extra(0) = 0
extra(1) = min(a, b)
extra(2) = min(2·a, b)

## Оценка сложности

- Обработка одного набора: **O(1)** — константное количество арифметических операций.
- Общая сложность: **O(t)**, где `t ≤ 10⁴`.
- Программа выполняется за доли секунды.

## Используемые технологии

- C# (.NET)
- F# (.NET)
- Prolog (SWI-Prolog)
- Целочисленная арифметика (64-битные числа)
- `StringBuilder` для эффективного вывода (C#, F#)

## Решения

### C# (императивный стиль)

Прямолинейная реализация с циклом `for`, чтением строк и разбором через `Split`. Результаты накапливаются в `StringBuilder` для быстрого вывода.

```
long full = n / 3;
long rem  = n % 3;
long cost = full * Math.Min(b, 3 * a);
if (rem == 1) cost += Math.Min(a, b);
else if (rem == 2) cost += Math.Min(2 * a, b);
```

F# (функциональный стиль)
Используется иммутабельный подход с функциями и pattern matching:

```
let solve (n: int64) (a: int64) (b: int64) =
    let full = n / 3L
    let rem  = n % 3L
    let base' = full * (min b (3L * a))
    let extra =
        match rem with
        | 0L -> 0L
        | 1L -> min a b
        | _  -> min (2L * a) b
    base' + extra
```

Prolog (логический стиль)
Реализованы предикаты:

process(T) — рекурсивная обработка T наборов.

extra(Rem, A, B, E) — вычисление стоимости остатка.

Используется read_line_to_string + split_string для чтения трёх чисел из одной строки. Хвостовая рекурсия для перебора наборов.

```
extra(0, _, _, 0).
extra(1, A, B, E) :- E is min(A, B).
extra(2, A, B, E) :- E is min(2 * A, B).
```
