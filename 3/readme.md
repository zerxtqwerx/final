# Codeforces 2230D - Хорошее расписание

## Условие задачи

Алиса и Боб смотрят сериал из n серий. В i-й день у Алисы показывают серию a[i], у Боба - b[i]. Процесс просмотра: серия смотрится только если все предыдущие серии (1..x-1) уже просмотрены. Выбрать отрезок [L,R] такой, что каждый день выполняется: либо оба смотрят одну серию, либо оба ничего не смотрят. Найти количество таких отрезков.

## Решения

### Задание 1. C# алгоритм

Файл: `1.cs`

Эффективный алгоритм O(n) по времени и O(n) по памяти. Использует предподсчёт next/prev вхождений и динамическое обновление минимального L для каждого R.

### Задание 2. Описание решения C#
