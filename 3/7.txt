Решение использует предикаты с накоплением состояния через рекурсию. Основные компоненты:

compute_positions - для каждого значения x сохраняет позицию в массиве A и B (последнюю встреченную)

compute_next_prev - строит для каждой позиции следующее и предыдущее вхождение того же значения

compute_max_reach - рекурсивно проходит позиции от 1 до N, для каждой вычисляет минимальный допустимый L

check_last, check_prevA, check_prevB, check_crossA, check_crossB - пять типов проверок конфликтов

compute_sum_loop - финальный подсчёт суммы (R - maxReach[R] + 1)

Все циклы заменены на рекурсию. Массивы представлены как списки, доступ по индексу через nth0.
